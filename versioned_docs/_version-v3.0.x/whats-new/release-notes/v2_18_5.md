# Version 2.18.5 (January 2026)

Welcome to the Zowe Version 2.18.5 release!

See [Bug fixes](#bug-fixes) for a list of issues addressed in this release.

**Download v2.18.5 build**: Want to try new features as soon as possible? You can download the v2.18.5 build from [Zowe.org](https://www.zowe.org/download.html).

## New features and enhancements

Zowe Version 2.18.5 contains the enhancements that are described in the following topics.

#### zlux-app-server
- App-server now supports separate server and client TLS certificates. Define `zowe.certificate.keystore.clientCertificateAlias` (for keyrings) or `zowe.certificate.pem.clientCertificate` and `zowe.certificate.pem.clientKey` (for PEM files) to use a dedicated client certificate for all outbound connections. The main certificate continues to be used for serving HTTPS. When not defined, the existing certificate is used for both as before. [(#375)](https://github.com/zowe/zlux-app-server/pull/375)
- `initInstance` now uses the `execFileSync` function to copy plug-in preference files into the instance during initialization, making preference setup more consistent and automatic. ([#379](https://github.com/zowe/zlux-app-server/pull/379))

### Zowe API Mediation Layer

- Implemented the `zowe.network.allowedDomains` allowlist property for URL domains. This feature validates all service registration metadata against a trusted domain allowlist. Current feature implementation in version 2.18.5 only issues warnings for unlisted domains by default. Full feature implementation is scheduled for subsequent v2.18.x versions to prevent unauthorized services from onboarding. ([#4689](https://github.com/zowe/api-layer/issues/4689))

## Bug fixes

Zowe Version 2.18.5 contains the bug fixes that are described in the following topics.

### Zowe Common C

- Updated `zosResolveSymbol()` to use the bounded %.*s form of `snprintf`, that prevents string overreads that can trigger an `ABEND` and also improve runtime stability. ([#595](https://github.com/zowe/zowe-common-c/pull/595))

### Zowe API Mediation Layer

* Restricted caching to items originating exclusively from trusted proxies. ([#4706](https://github.com/zowe/api-layer/issues/4706))
* Fixed Server-Sent Events (SSE) data corruption issues. ([#4530](https://github.com/zowe/api-layer/issues/4530))
* Resolved an issue preventing all headers from being written in HTTP responses. ([#4522](https://github.com/zowe/api-layer/issues/4522))
* Downgraded the domain allowlist enforcement to issue warnings by default in version 2.18.5. ([#4733](https://github.com/zowe/api-layer/issues/4733))
* Applied relaxed firewall rules strictly to routed requests (v2). ([#4666](https://github.com/zowe/api-layer/issues/4666))
* Standardized the host verification scheme to align with the rest of the Gateway. ([#4667](https://github.com/zowe/api-layer/issues/4667))

### Zowe CLI

#### Zowe CLI (Core)

- Updated `tar` dependency to resolve technical currency. [#2668](https://github.com/zowe/zowe-cli/pull/2668)

#### Zowe CLI Imperative Framework

- Removed large dependency `pacote` for fetching package metadata when installing plug-ins. ([#2668](https://github.com/zowe/zowe-cli/pull/2668))
- Fixed truncation that could occur when the `AbstractRestClient` request method downloads gzip-encoded data. ([#2661](https://github.com/zowe/zowe-cli/pull/2661))
