zowe › endevor › queryacm

Query components used by element, or elements using component in Endevor.

Usage

zowe endevor queryacm <command>

Where <command> is one of the following:

Commands

  • components-using-element | comp - | Query components used by a specified
  • components - Element with the Endevor ACM Query facility.
  • elements-using-comment | comm | comment - Query elements using a comment component with the Endevor ACM Query facility.
  • elements-using-element | ele | element - Query elements using an element component with the Endevor ACM Query facility.
  • elements-using-member | mem | member - Query elements using a member component with the Endevor ACM Query facility.
  • elements-using-object | obj | object - Query elements using an object component with the Endevor ACM Query facility.
