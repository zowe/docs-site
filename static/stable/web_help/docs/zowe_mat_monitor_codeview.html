zowe › mat › monitor › codeview

Get the CodeView measurement details.

Usage

zowe mat monitor codeview <command|group>

Where <command|group> is one of the following:

Commands

  • callerid | cil - Get CodeView CallerID details
  • csect | cs - Get CodeView data in CSECT mode
  • ideal | idl - Get CodeView data in Ideal mode.
  • module | mod - Get CodeView data in Module mode
  • natural | nat - Get CodeView data in Natural mode.

Groups

  • histogram | hsg - Get Histogram data
