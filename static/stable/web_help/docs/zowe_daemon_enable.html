zowe › daemon › enable

Enable daemon-mode operation of the Zowe CLI. You only need to run the enable command once after each new installation of the Zowe CLI. Afterwards, any zowe command automatically starts a daemon as needed.

Ensure the Zowe daemon bin directory is on your PATH. If it isn't, the command will instruct you to add it manually. Otherwise, you continue to run the classic Zowe CLI interpreter.

Usage

zowe daemon enable [options]

Examples

  • Enable daemon-mode:

    • zowe daemon enable
