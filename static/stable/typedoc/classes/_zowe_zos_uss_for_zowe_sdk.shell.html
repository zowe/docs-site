Static Private hostVerifier

  • hostVerifier(session: SshSession, connState?: IConnectionState): (Anonymous function)
    • Defined in @zowe/zos-uss-for-zowe-sdk/src/Shell.ts:323

    Build the ssh2 host key verifier callback. Host key verification runs during the SSH handshake, before any credentials are sent, so an untrusted server never receives the user's password.

    The presented key is trusted when:

    • host key verification is disabled (insecure === true), or
    • it matches the pinned ISshSession.hostKey.

    Otherwise (no pinned key, or the key changed) the decision is delegated to the session's interactive SshSession.hostKeyVerifier hook if one is set (trust on first use); when no hook is available (e.g. non-interactive SDK usage) the connection is rejected.

    Parameters

    • session: SshSession

      the SSH session being connected

    • Optional connState: IConnectionState

      optional state updated when a key is rejected, so a clear error can be surfaced

    Returns (Anonymous function)

    an ssh2 hostVerifier callback
